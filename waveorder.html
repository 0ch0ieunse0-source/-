01

Overview

웨이브오더는 케이크·디저트를 주문 제작하는 소규모 매장의 점주가 겪는 반복적인 운영 문제에서 출발했습니다. 인스타그램 DM, 카카오톡, 네이버 톡톡 등으로 흩어진 문의를 하나의 채팅 화면에서 관리하고, 링크 하나로 주문을 받아 예약부터 픽업까지 이어지게 하는 것이 핵심입니다.

초기에는 B2C 관점으로 접근했지만, 점주 인터뷰를 거치며 대기업 예약 서비스와 정면 경쟁하는 구조가 현실적이지 않다는 것을 확인하고 점주 중심의 통합 관리 솔루션으로 문제를 다시 정의했습니다.

02

Background

레터링 케이크·디저트는 대부분 예약 제작 방식으로 운영됩니다. 점주들은 인스타그램 DM과 카카오톡, 네이버 톡톡을 동시에 확인하며 문의에 답하고, 제작 일정과 픽업 시간을 별도로 관리해야 했습니다. 채널이 늘어날수록 정작 케이크를 만드는 시간은 줄어드는 구조였습니다.

03

Problem

점주들은 여러 주문 채널을 관리하고 고객을 응대하느라, 정작 제작에 집중할 시간이 부족했습니다.

04

Research

점주의 불편함만이 아니라, 늘어난 소비량에 비해 복잡한 주문 과정에서 불편을 느끼는 고객도 확인했습니다.

46%
주 1회 이상 디저트를 구매하는 고객 비율
60%
디저트 구매 시 번거로움을 느끼는 고객 비율
852명
2024.12.30 – 2025.03.05 온라인 수요조사 대상

여고·대학교·민간 및 공공기관 등 852명을 대상으로 한 온라인 수요조사에서 "예약 과정이 복잡하다", "매장마다 주문 채널이 다르다", "주문 양식이 너무 길다"는 응답이 반복적으로 확인됐습니다.

점주와 고객은 같은 지점에서 불편함을 느끼고 있었습니다 — 흩어진 채널과 복잡한 예약 방식.

05

Insight · Positioning

맞춤 제작과 대화 기반 예약을 동시에 다루는 플랫폼이 시장에 없다는 점을 확인했습니다. 정형화된 예약 시스템은 맞춤 제작 문의에 대응하기 어렵고, 단순 메뉴 예약 중심 서비스는 픽업 관리 기능이 약했습니다.

이 빈 자리 — 비정형 대화 기반 맞춤 예약 + 픽업 관리 — 를 웨이브오더의 포지션으로 설정했습니다.

고객 유입

인스타그램 · 카카오톡 · 네이버 톡톡으로 흩어진 채널

예약 관리

대화 중 예약 정보를 바로 확인·수정

픽업 관리

제작 단계를 상태값으로 필터링

채팅 관리

반복 문의 자동 응답으로 대응 시간 단축

06

Solution

흩어진 채널을 하나로 모아, 예약 · 픽업 · 채팅 관리로 연결했습니다.

As is

주문서 양식을 복사한 뒤 픽업 날짜·연락처·케이크 디자인 등 항목을 하나하나 수기로 입력

To be

단일·다중·수량·텍스트·컬러 등 다양한 옵션 형태로 주문서를 구성하고, 고객 주문 화면을 실시간으로 미리보기

중요 문의 우선 관리

놓치면 안 되는 대화를 중요 채팅으로 지정해 빠르게 확인할 수 있도록 했습니다.

대화 중 예약 정보 즉시 확인 · 수정

채팅과 예약 정보 화면을 오갈 필요 없이, 해당 고객의 주문 정보를 함께 확인하고 픽업 일정도 대화 화면에서 바로 수정할 수 있도록 했습니다.

채널 아이콘으로 유입 경로 구분

문의가 들어온 채널을 아이콘으로 표시해 고객의 유입 경로를 한눈에 파악할 수 있도록 했습니다.

주문 상태별 필터링

준비중 · 호출완료 · 픽업완료 등 상태를 기준으로 필터링해 당일 처리해야 할 주문을 빠르게 찾을 수 있도록 했습니다.

반복 문의 자동 응답 + 주문 링크

주문 가능 시간, 기본 안내처럼 반복되는 문의는 자동 응답으로 처리하고, 고객은 링크를 통해 직접 주문할 수 있도록 해 접수된 주문을 하나의 리스트로 모았습니다.

07

Design

Pretendard 기반 타이포그래피와 컬러 시스템을 정의하고, Midjourney와 ChatGPT를 활용해 브랜드 캐릭터를 제작했습니다. 캐릭터 의상에 서비스 로고를 반영해 브랜드와 캐릭터가 하나의 경험으로 이어지도록 했습니다. (AI로 초안을 생성하고, 세부 형태와 적용 방식은 직접 다듬었습니다.)

08

Result

기능을 만들기 전 실행 가능 여부부터 확인했습니다. 2025년 2월 카카오톡 공식 파트너사 채널코퍼레이션에 상담톡 연동 협조 공문을 회사 명의로 직접 발송했고, 3월에는 복수 업체의 API 연동 조건과 견적을 비교해 서비스에 맞는 업체를 선정했습니다.

MVP 출시
점주용 팜플렛·굿즈 제작, 온라인 사업 설명회와 서울 디저트 페어 현장 홍보로 실제 사용 점주를 확보했습니다.

출시 이후에는 점주 모니터링에 참여해 운영 과정에서 나오는 불편과 요구사항을 지속적으로 확인하고, 이를 서비스 고도화 기획과 디자인으로 연결했습니다.

09

Reflection

처음 세운 B2C 가정을 점주 인터뷰 결과로 뒤집었던 경험이었습니다. "좋아 보이는 방향"이 아니라 실제 현장에서 나온 숫자와 문장을 근거로 서비스 구조를 다시 짜는 판단이 이 프로젝트에서 가장 중요했습니다. 디자인 이전에, 무엇을 만들지 자체를 검증하는 단계가 있어야 한다는 것을 확인했습니다.
